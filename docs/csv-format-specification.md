# Tiered Output CSV Format Specification

## Overview

This document specifies the CSV file format for tiered output files generated by the tier assignment system (Story 1.1, Story 2.4).

## File Names

| Tier | Filename | Description |
|------|----------|-------------|
| Tier 1 | `auto_merge_pairs.csv` | Pairs safe for automatic merging (0% FP rate) |
| Tier 2 | `review_queue_pairs.csv` | Pairs requiring manual review (>0% FP rate) |

Files are saved in the input run directory (e.g., `_bmad-output/analysis/run_2026010112345/`).

## Encoding

- **Character Encoding**: UTF-8 with BOM (Byte Order Mark)
- **Implementation**: `encoding='utf-8-sig'` in pandas
- **Purpose**: Ensures German/Swiss characters (ä, ö, ü, ß) display correctly in Microsoft Excel without manual encoding selection

## Delimiter

- **Delimiter**: Comma (`,`)
- **Format**: Standard CSV (RFC 4180 compliant)
- **Note**: Comma delimiter is widely compatible across tools and locales

## Column Order

Columns are ordered for business readability:

| Order | Column | Description |
|-------|--------|-------------|
| 1 | `match_id` | Unique pair identifier (format: `{i}_{j}`) |
| 2 | `cluster` | Cluster assignment (0-14) |
| 3 | `confidence` | Match confidence score |
| 4 | `i` | First record ID |
| 5 | `j` | Second record ID |
| 6+ | (remaining) | Original record fields in source order |

## Data Types

| Column | Type | Range/Format |
|--------|------|--------------|
| `match_id` | String | `{i}_{j}` format |
| `cluster` | Integer | 0-14 |
| `confidence` | Float | 0.0-1.0 |
| `i`, `j` | Integer | Record IDs |

## Example Output

```csv
match_id,cluster,confidence,i,j,name_A,name_B,address_A,address_B
100_200,3,0.95,100,200,Müller Hans,Mueller Hans,Zürich,Zurich
101_201,4,0.92,101,201,Schmidt Peter,Schmid Peter,Bern,Bern
```

## Excel Compatibility

The format is tested for compatibility with:
- Microsoft Excel (Windows, German locale)
- Microsoft Excel (macOS)
- LibreOffice Calc
- Google Sheets

### Opening in Excel

1. Double-click the CSV file - Excel auto-detects UTF-8 BOM encoding
2. German characters display correctly without import wizard

## Validation

The system validates:
- All pairs are in exactly one tier (no duplicates, no missing)
- Cluster values are in valid range (0-14)
- No data loss between input and output
